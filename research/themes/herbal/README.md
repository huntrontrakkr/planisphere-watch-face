# Theme: The Herbal (nature through the year)

status: in progress (started 2026-10-16)

Faint background sprigs (~60 x 25 px scenes, 25-40 px sprigs) and 20-24 px
moon-phase corner pieces, drawn from real period herbals and almanacs.
Licence rule: public domain / CC0 only (PD-Art on Wikimedia Commons OK).

## Sources

### S1. Fuchs, De historia stirpium (Basel, 1542) -- prefix `fuchs1542-`
- Leonhart Fuchs, *De historia stirpium commentarii insignes*, Basel: Michael
  Isingrin, 1542. Drawings Albrecht Meyer, transferred to the block by Heinrich
  Füllmaurer, cut by Veit Rudolph Speckle.
- Copy: Smithsonian Libraries, Dibner Library (scanned for the Biodiversity
  Heritage Library). Internet Archive id `Dehistoriastirp00Fuch`,
  https://archive.org/details/Dehistoriastirp00Fuch
- Licence: public domain ("The BHL considers that this work is no longer under
  copyright protection"; book 1542).
- Each file = one full-page plate, fetched from
  `https://archive.org/download/Dehistoriastirp00Fuch/page/n<N>_w1400.jpg`
  (N = scan leaf, listed per file in the table below), trimmed to the printed
  area, max 2000 px. Plates carry a Latin caption at left and German at right.
  Leaf n548 (corn poppy) is hand-coloured red in this copy.
- Note: the Wellcome images of Fuchs on Commons are CC BY 4.0, so not used
  (also, the Wellcome "holly and platen" is Isingrin's printer's device, not a
  holly plant).

### S2. Bock, Kreüter Buch (Strasbourg, 1546) -- prefix `bock1546-`
- Hieronymus Bock (Tragus), *Kreüter Buch, darin Underscheid, Würckung und
  Namen der Kreüter so in Deutschen Landen wachsen*, Strasbourg: Wendel Rihel,
  1546. First illustrated edition; woodcuts by David Kandel. This copy is
  contemporary hand-coloured; figures sit inside the text column, so each file
  is cropped to the figure.
- Copy: Missouri Botanical Garden (Peter H. Raven Library), via BHL. Internet
  Archive id `mobot31753000815859`,
  https://archive.org/details/mobot31753000815859
- Licence: public domain (BHL METS accessCondition: "Public domain. The BHL
  considers that this work is no longer under copyright protection.").
- Page URL pattern `https://archive.org/download/mobot31753000815859/page/n<N>_w1400.jpg`.

### S3. Bock, Kreüter Buch (Strasbourg, 1560) -- prefix `bock1560-`

- Copy: Missouri Botanical Garden via BHL. Internet Archive id
  `mobot31753000820529`, https://archive.org/details/mobot31753000820529

### S4. Regiomontanus, Kalendarium (Venice: Ratdolt, 1482) -- prefix `kalendarium1482-`

- Copy: Bibliothèque Sainte-Geneviève, Paris, OEXV 540 RES (P.1). Internet

- Licence: Public Domain Mark 1.0 (IA licenseurl; "domaine public").
- Files: `BSG_OEXV540_P1__02_000039.jpg` (eclipses 1487-1491),
  `..._000041.jpg` (eclipses 1497-1504), `..._000068.jpg` (moon volvelle),
  cropped.

Short list for the card, one or two strong sprigs per month:
Jan hellebore (leaf fan) / snowflake; Feb snowflake / squill; Mar daffodil /
violet; Apr cowslip / daisy (n181); May lily of the valley / columbine; Jun
rose stem / strawberry; Jul corn poppy / foxglove; Aug wheat ear / barley; Sep
grape bunch / hops cone; Oct oak tree / chestnut / apple; Nov medlar / ivy
leaf; Dec holly / mistletoe fork.

Not found in a PD period source in this pass: hawthorn (Fuchs's
"Oxyacantha" n576 is barberry, his "Spina alba" n88 a thistle) and a true
snowdrop (*Galanthus*; first figured later, e.g. Gerard 1597 "Leucoium
bulbosum praecox minus" - Gerard 1597 is on IA as `mobot31753000817749`
if wanted). Snowflake and squill stand in for February.
